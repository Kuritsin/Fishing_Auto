# WoW Fishing Bot — первый компактный прототип

Бот работает только по изображению экрана: он не читает память игры, не делает
инъекций и не перехватывает сеть. Автоматизация может нарушать правила World of
Warcraft; пользователь принимает этот риск самостоятельно.

## Перед началом

1. Windows 10/11, Python 3.12 и World of Warcraft Anniversary.
2. Включите **Auto Loot**.
3. Выключите **Click to Move**.
4. Поместите Fishing на клавишу, которую укажете мастеру.
5. Не меняйте камеру во время одного заброса.

## Установка и запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

При первом запуске мастер сам определит размер активного окна WoW и сделает
три тестовых заброса. На каждом кадре зажмите левую кнопку и обведите рамкой
весь поплавок — перья и корпус, но без длинной лески. Программа сохранит несколько
его видов; слишком маленькие изображения и маски использоваться не будут. Это помогает
при анимации и движущейся воде. Чтобы повторить привязку после крупного обновления, смены
масштаба или модели поплавка, выполните `python main.py --setup`.

После обновления со старой версии также один раз повторите `python main.py --setup`:
новый профиль сохраняет маску и точку корпуса для каждого шаблона.

## Безопасность

- `F8` — пауза/продолжение;
- `F10` — безопасная остановка;
- `Ctrl+C` — остановка из консоли;
- `python main.py --dry-run --once` — одна попытка без реального ввода.

В рабочем dry-run бот попросит выполнить заброс вручную, но не будет двигать
мышь или нажимать ПКМ. С флагом `--debug` последние выбранный кандидат, маска
новизны и точка предполагаемого клика сохраняются в каталоге `debug/`.

Если переключиться из WoW в другое окно, бот не завершается: он отменяет
небезопасное действие, ждёт возвращения в WoW и затем продолжает работу. Во
время настройки после каждого выбора поплавка также нужно вернуться в игру;
мастер будет ждать без ошибки и без ограничения времени.

Незавершённая повторная настройка не заменяет предыдущие рабочие шаблоны.
После распознанной поклёвки строка `ПКМ выполнен: (x, y)` в журнале отдельно
подтверждает, что проверка активного окна разрешила реальный клик.

Перед каждым нажатием, перемещением и кликом проверяется, что WoW является
активным окном. Для добычи используется обычный ПКМ без Shift; перед ним
принудительно отпускаются Shift, Ctrl и Alt.

Курсор движется по короткой плавной кривой с разгоном и замедлением. Это сделано
для визуально естественного движения, а не для обхода защиты игры; конечная
точка остаётся точной, а потеря фокуса немедленно отменяет движение и клик.

## Текущий этап

Это проверяемый прототип: автоматическое создание нескольких компактных шаблонов, быстрый поиск,
единый локальный tracker поклёвки и диагностика оставшегося loot window. До
первой проверки на Windows используйте `--dry-run`.

## Если файлы обновились не одновременно

Ошибка о разных версиях `bot.py` и `vision.py` означает, что на компьютере
оказалась смесь файлов из разных commit. Обновите весь репозиторий, закройте
запущенные процессы Python и удалите каталоги `__pycache__`. Проверить API можно
командой:

```powershell
python -c "from fishing_bot.bot import validate_vision_api; validate_vision_api(); print('OK')"
```

## Проверка записанного видео

Разработчик может прогнать тот же детектор без запуска игры и получить CSV с
траекторией. Начальный кадр должен содержать спокойно стоящий поплавок, а `x/y`
задают его центр:

```powershell
python -m tools.replay_video bobber_vid.mp4 --start 4 --end 12 --x 858 --y 622
```
