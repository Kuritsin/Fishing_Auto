# WoW Fishing Bot — первый компактный прототип

Бот работает только по изображению экрана: он не читает память игры, не делает
инъекций и не перехватывает сеть. Автоматизация может нарушать правила World of
Warcraft; пользователь принимает этот риск самостоятельно.

## Перед началом

1. Windows 10/11, Python 3.12 и World of Warcraft Anniversary.
2. Включите **Auto Loot**.
3. Выключите **Click to Move**.
4. Поместите Fishing на клавишу, которую укажете мастеру.
5. Не меняйте камеру во время одного заброса.

## Установка и запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

При первом запуске мастер сам определит размер активного окна WoW, сделает
тестовый заброс и покажет кадр. Кликните по поплавку — программа сама сохранит
его текущий шаблон. Чтобы повторить привязку после крупного обновления, смены
масштаба или модели поплавка, выполните `python main.py --setup`.

## Безопасность

- `F8` — пауза/продолжение;
- `F10` — безопасная остановка;
- `Ctrl+C` — остановка из консоли;
- `python main.py --dry-run --once` — одна попытка без реального ввода.

Перед каждым нажатием, перемещением и кликом проверяется, что WoW является
активным окном. Для добычи используется обычный ПКМ без Shift; перед ним
принудительно отпускаются Shift, Ctrl и Alt.

## Текущий этап

Это первый проверяемый прототип: автоматическое создание шаблона, быстрый поиск
и единый локальный tracker поклёвки. Следующий этап — прогнать tracker по
реальным видео, откалибровать относительные пороги и добавить визуальную
проверку оставшегося loot window. До этой проверки используйте `--dry-run`.
